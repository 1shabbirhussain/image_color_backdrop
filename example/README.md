# image_color_backdrop example

A small app that shows what the
[image_color_backdrop](https://pub.dev/packages/image_color_backdrop) package
can do:

- **Gallery**: the same logos on backdrops picked from their own colors, in
  several styles, strategies and gradients.
- **Playground**: change the strategy, region, opacity, brightness, saturation
  and gradient live and watch the extracted palette.
- **Use the color**: color a whole page, a card and a container from an image
  with `BackdropController`, `BackdropColorBuilder` and `ImageBackdrop`.

Run it with:

```sh
flutter pub get
flutter run
```

The main code is in [`lib/main.dart`](lib/main.dart).
